# Release Notes v0.4.0 — Experience Renderer v2 + Scheduled Promotion UI

- Experience Renderer v2 consumes canonical theme, typography and layout tokens.

- Customer home reads active scheduled promotions as readable merchandising UI.
- No raw JSON customer-facing data views.
