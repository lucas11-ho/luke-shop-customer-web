# Customer Web v0.9.2 — Google Maps + Delivery Address Pro

## Added
- Google Maps JavaScript API runtime loader.
- Places API (New) `PlaceAutocompleteElement` address/place search.
- Mobile-friendly map pan + fixed center pin selection.
- Current-location shortcut using browser Geolocation.
- Explicit `Confirm this pin` action with `MAP_PIN` provenance.
- Backend reverse geocoding after GPS or map confirmation.
- Responsive map UI for saved addresses and checkout.

## Preserved
- Written address fields remain editable and authoritative before save/checkout.
- Existing saved-address CRUD, default address, checkout snapshots and order live-location features remain intact.
- Customer Authentication Pro v0.9.1 remains carried forward.
