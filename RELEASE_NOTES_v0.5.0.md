# Luke Shop Customer Web v0.5.0 — Storefront Renderer v3

Baseline: v0.4.0

## Built

- Adds the secure Store Designer iframe bridge for signed preview routes only.
- Implements heading/body scale fixes and Experience schema v3 responsive tokens.
- Adds approved web-font stylesheet delivery while preserving iOS/native system stacks.
- Adds SEO title, description, Open Graph image, and favicon rendering.
- Implements real hero slider, featured-product hero, video hero with image fallback, full-width media hero, split/minimal variants, and responsive media positioning.
- Implements category circles, real image tiles when public category imagery exists, cards/chips/horizontal modes.
- Implements compact/horizontal product grids and technical/editorial/soft/quick-add product cards.
- Adds guarded quick-add; products with variants or insufficient fulfillment information open the product detail flow instead.
- Implements iOS-style mobile navigation and transparent header treatment.
