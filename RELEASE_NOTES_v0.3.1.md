# Luke Shop Customer Web v0.3.1 — Commercial Storefront UX Polish

Adds tenant campaign-media hero treatment, adaptive category rails for sparse catalogs, discount/stock merchandising, richer product-card affordance, published search-feature behavior, mobile polish, loading treatment, and keyboard focus states. No API or database changes.

## Compatibility

- Backend: v0.8.0 unchanged
- Database migrations: unchanged through 009
- Tenant routing/auth/permissions: unchanged
- Existing `.env` and `package-lock.json` must be preserved by the upgrade installer.
