# Luke Shop Customer Web v0.2.0 — Server-Driven Storefront Experience

## Added
- Consumes only the Backend v0.7.0 published storefront experience.
- Server-driven theme tokens, branding, announcement, navigation, and home-section order.
- Safe renderer for hero, hero slider alias, categories, featured products, new arrivals, promotion banners, and announcement blocks.
- Existing catalog/cart/checkout/orders/support contracts remain unchanged.

## Boundary
The customer frontend is read-only for experience configuration. Draft, publish, and rollback remain merchant-admin operations. No migration is included in this frontend release.
