# LUKE_SHOP_CUSTOMER_WEB — current release v0.9.1

Customer Web v0.9.1 introduces **Customer Authentication Pro** for Shop Backend v0.14.1.

- Official Google Identity Services button.
- Current Telegram Login/OIDC popup with server-issued nonce.
- Cloudflare Turnstile on email/password authentication according to merchant policy.
- Google and Telegram identity linking in Login & Security.
- Forgot Password removed until real recovery delivery exists.
- Existing Commerce Connector v2, profile, GPS, fulfillment and storefront features remain carried forward.
