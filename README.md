# LUKE_SHOP_CUSTOMER_WEB — current release v0.9.3

Customer Web v0.9.3 is **Step 1: Mobile Authentication UX Pro** on top of Google Maps + Delivery Address Pro.

- Mobile-first Sign In / Sign Up layout.
- Email/password primary action appears first.
- Official Google GIS circle/icon control and compact Telegram control appear below the main action.
- Turnstile remains enforced by the existing backend policy but uses interaction-only presentation on auth pages.
- Password visibility toggle, touch-friendly controls, dynamic viewport sizing and safe-area support.
- Forgot Password remains intentionally unimplemented and hidden.
- All v0.9.2 Google Maps + Delivery Address functionality is carried forward.

See `RELEASE_NOTES_v0.9.3.md`, `TECHNICAL_ANALYSIS_v0.9.3.md`, `TEST_RESULT_v0.9.3.md` and `DEPLOYMENT_CHECKLIST_v0.9.3.md`.
